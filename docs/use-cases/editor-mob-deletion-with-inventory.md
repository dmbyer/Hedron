# Editor: Mob Deletion with Inventory

**Status:** planned
**Actors:** Administrator, Web Editor
**Module:** Admin app + `Core/Modules/WorldEditing/`

## Description

An administrator deletes a mob **prototype** that has items assigned to its `InventoryComponent`. Carried item prototypes must be handled per policy (keep, delete if autogenerated, or orphan-quarantine). Room/area references pointing at the mob must be scrubbed.

## Preconditions

- Admin has required privilege
- Mob prototype exists
- Mob may have inventory item prototype references
- No live instances of the mob are currently in combat (otherwise, refuse or schedule)

## Postconditions

- Mob prototype removed from cache and disk
- Inventory item prototypes handled per policy (delete autogenerated; keep shared; quarantine orphans)
- All area/room prototype references to the mob are cleaned
- Any live instances spawned from this prototype are destroyed
- UI reflects the removal

## Main flow

1. Admin selects mob in Mob Editor → "Delete"
2. `WorldEditingSystem.PlanMobDeletion(mobPrototypeId)` → manifest:
   - Referencing area/room prototypes
   - Inventory prototype references with their autogenerated flags
   - Live instances
3. Admin confirms
4. `WorldEditingHandler` orchestrates:
   - Destroy every live instance via `EntityService.DestroyEntity`
   - Scrub the mob reference from each area/room prototype's spawn list
   - For each inventory prototype: apply policy (delete / keep / quarantine)
   - Remove mob prototype from `ComponentRepository`
   - Mark disk paths for removal → `PersistenceHandler` flushes
5. Handler publishes `MobPrototypeDeletedEvent`
6. UI refreshes

## Events fired

- `MobPrototypeDeletedEvent` _(planned)_
- `EntityDestroyedEvent` — for each live instance
- `PrototypeReferenceScrubbed` _(planned)_ — for each referencing prototype

## Systems / handlers

- `WorldEditingSystem`, `EntityService`, `PersistenceHandler`
- `WorldEditingHandler` — orchestrator

## Design notes

- **Autogenerated vs authored items** is a flag on the item prototype. The deletion policy is "delete autogenerated, keep authored, quarantine shared-but-now-orphaned."
- **Reference scrubbing** lives in `WorldEditingSystem` — not in every handler that could host a mob reference. One source of truth.
- **Live instances die immediately.** An admin edit is an authoritative rewrite of world state.
